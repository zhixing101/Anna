### Q3:如何放到 GitHub Pages，并告诉参与的朋友，反馈需求

## 一、放到 GitHub Pages

1. **准备文件**：把下载的 `timespace.html` 改名为 `index.html`，GitHub Pages 会把它当作首页。
2. **新建仓库**：登录 GitHub，点右上角“+”→ New repository，名称比如 `timespace`，选 Public（免费账号的 Pages 需要公开仓库），点创建。
3. **上传文件**：在新仓库页面点 “uploading an existing file”，把 `index.html` 拖进去，点 Commit changes。
4. **开启 Pages**：进入仓库的 Settings → Pages，在 Build and deployment 里 Source 选 “Deploy from a branch”，Branch 选 `main`、目录选 `/ (root)`，保存。
5. **等待并打开**：约 1 到 2 分钟后，页面顶部会显示你的网址，格式是 `https://你的用户名.github.io/timespace/`。
6. **更新页面**：以后我改了页面，你只需重新上传同名文件覆盖即可。

GitHub 的界面偶尔会微调，如果某个按钮找不到，按名称在 Settings 里搜一下即可。Pages 是 HTTPS，所以页面里的麦克风录音和语音转文字也能正常使用。

## 二、怎么告诉朋友

可以直接把这段发出去，网址换成你自己的：

> 打开：https://你的用户名.github.io/timespace/

## 三、怎么收到反馈

目前页面的反馈只存在每个朋友自己的浏览器里，所以必须让朋友点“复制”或“邮件发送”再发给你。更省事的做法是改成提交到 GitHub Issues：在反馈面板里加一个“提交到 GitHub”按钮，点击后跳到你仓库的新建 Issue 页，标题和内容已预填好，你在仓库的 Issues 里就能集中查看、分类、回复，还能关闭已完成的需求。缺点是朋友需要有 GitHub 账号，没有的人仍可用邮件。
