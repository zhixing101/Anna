# 一、什么是「12金句法」？

你说的「12金句法」，通常指美国作家、企业家 Tim Ferriss（蒂姆·费里斯） 推广的语言解构方法：

英文名称：The Deconstruction Dozen，也称 12-Sentence Audit（12句语言结构分析法）。

它的核心思想是：

> 不要一开始就从头到尾学习一本语法书，而是先用12个简单句子，观察一门语言是怎样组织起来的。

这12句话看起来非常简单，但涉及名词、代词、动词变化、语序、所有关系、宾语、疑问句、否定句、情态动词和时间表达。

它不是12句背熟就能掌握一门语言，而是用12句话作为一把钥匙，先打开一门语言的语法结构。

Tim Ferriss 在2007年11月7日发表的文章 How to Learn (But Not Master) Any Language in 1 Hour 中介绍了这一思路。后来又在《The 4-Hour Chef》中详细介绍了12句版本。

### 1. 创立背景

Ferriss 在普林斯顿大学进行过神经科学相关研究，研究主题涉及英语母语者非传统方式学习日语。

他在重新设计 Berlitz 语言课程以及学习多种外语的过程中，注意到一个问题：

很多人刚开始学习一门外语，就陷入大量语法规则、单词和教材之中，却没有先了解这门语言的基本结构。

于是他采用了一种更有针对性的方法：

1. 先找母语者。
2. 给对方12个英文句子。
3. 请对方翻译成目标语言。
4. 观察词语顺序、动词变化、代词和语法结构。
5. 根据差异判断这门语言的学习难点。

他还将其称为语言的「解构」（Deconstruction）。

### 2. 与历史语言学习者的联系

这个方法也有一个有趣的历史背景。

Giuseppe Mezzofanti（朱塞佩·梅佐凡蒂）（1774—1849）是一位著名的多语言学者。

Ferriss 在《The 4-Hour Chef》中介绍了 Mezzofanti 利用《主祷文》（The Lord's Prayer）学习和分析不同语言的方法。

因为一篇简短的祷文就包含了许多语法现象，例如：

- 主语和宾语
- 所有关系
- 动词形式
- 命令和请求
- 否定表达
- 介词和格的关系

Ferriss 借鉴了这种思路，将其发展为12句解构法。这里要区分：Mezzofanti 是历史上的方法先例，不是现代12句法的直接创立者。

## 第一组：名词、形容词和所有关系

1—2 认识基本结构

1\. The apple is red.

| 语言      | 表达                |
| ------- | ----------------- |
| 中文      | 苹果是红色的。           |
| English | The apple is red. |
| 日本語     | そのりんごは赤いです。       |

语法观察：

- apple：名词
- red：形容词
- is：系动词
- 英语需要 be 动词连接主语和形容词。
- 日语可以直接使用形容词作谓语：赤いです。

2\. It is John's apple.

| 语言      | 表达                  |
| ------- | ------------------- |
| 中文      | 它是约翰的苹果。            |
| English | It is John's apple. |
| 日本語     | それはジョンのりんごです。       |

语法观察：

- John's：所有格。
- 日语用「の」表示所属。
- 中文用「的」。
- 三种语言表达所有关系的方式不同。

## 第二组：主语、直接宾语和间接宾语

3—6 认识动词和代词

3\. I give John the apple.

| 语言      | 表达                     |
| ------- | ---------------------- |
| 中文      | 我把苹果给约翰。               |
| English | I give John the apple. |
| 日本語     | 私はジョンにりんごをあげます。        |

语法观察：

- I：主语。
- John：间接宾语，接受者。
- the apple：直接宾语，给予的东西。
- 日语「に」表示给予对象，「を」表示直接宾语。

4\. We give him the apple.

| 语言      | 表达                     |
| ------- | ---------------------- |
| 中文      | 我们把苹果给他。               |
| English | We give him the apple. |
| 日本語     | 私たちは彼にりんごをあげます。        |

语法观察：

- We：主语从 I 变为 We。
- him：John 被代词替换。
- 英语中 he 是主格，him 是宾格。
- 日语的「彼」没有这种主格、宾格形态变化。

5\. He gives it to John.

| 语言      | 表达                   |
| ------- | -------------------- |
| 中文      | 他把它给约翰。              |
| English | He gives it to John. |
| 日本語     | 彼はそれをジョンにあげます。       |

语法观察：

- He：第三人称单数。
- gives：动词增加 -s。
- it：代替 apple。
- 英语采用 to John 表示给予对象。

6\. She gives it to him.

| 语言      | 表达                   |
| ------- | -------------------- |
| 中文      | 她把它给他。               |
| English | She gives it to him. |
| 日本語     | 彼女はそれを彼にあげます。        |

语法观察：

- She：女性第三人称。
- him：男性宾格代词。
- 英语通过代词体现性别和格。
- 日语中也可以使用彼女、彼，但实际对话经常省略人称代词。

## 第三组：疑问句和名词复数

7—8 认识句型变化

7\. Is the apple red?

| 语言      | 表达                |
| ------- | ----------------- |
| 中文      | 苹果是红色的吗？          |
| English | Is the apple red? |
| 日本語     | そのりんごは赤いですか。      |

语法观察：

- 英语将 is 放在主语前面，形成疑问句。
- 中文增加「吗」。
- 日语增加「か」。

8\. The apples are red.

| 语言      | 表达                  |
| ------- | ------------------- |
| 中文      | 苹果是红色的。             |
| English | The apples are red. |
| 日本語     | りんごは赤いです。           |

语法观察：

- apple → apples。
- is → are。
- 英语名词和动词都可能随数量变化。
- 中文名词通常不通过词尾变化表示复数。
- 日语一般也不强制标记名词复数。

这是非常有价值的一句，因为它能迅速揭示一门语言是否具有名词数的语法变化。

## 第四组：情态动词、意愿、将来和否定

9—12 认识复杂表达

9\. I must give it to him.

| 语言      | 表达                     |
| ------- | ---------------------- |
| 中文      | 我必须把它给他。               |
| English | I must give it to him. |
| 日本語     | 私はそれを彼にあげなければなりません。    |

语法观察：

- must：必须。
- 英语情态动词后面接动词原形 give。
- 日语使用「なければなりません」表达义务。

10\. I want to give it to her.

| 语言      | 表达                        |
| ------- | ------------------------- |
| 中文      | 我想把它给她。                   |
| English | I want to give it to her. |
| 日本語     | 私はそれを彼女にあげたいです。           |

语法观察：

- want to：想要做某事。
- her：女性宾格代词。
- 日语通过动词的「たい」形式表达愿望。

11\. I'm going to know tomorrow.

| 语言      | 表达                          |
| ------- | --------------------------- |
| 中文      | 我明天就会知道。                    |
| English | I'm going to know tomorrow. |
| 日本語     | 明日には分かるでしょう。                |

语法观察：

- be going to：表示将来。
- tomorrow：明天。
- 中文用「会」表达将来。
- 日语用「でしょう」表达推测或预期。

这里日语是自然意译，不是逐词对应。英文的 be going to 和日语的 でしょう 并非完全相同。

12\. I can't eat the apple.

| 语言      | 表达                     |
| ------- | ---------------------- |
| 中文      | 我不能吃这个苹果。              |
| English | I can't eat the apple. |
| 日本語     | 私はそのりんごを食べられません。       |

语法观察：

- can't：cannot，不能。
- 英语使用 can + 动词原形。
- 日语使用动词可能形的否定形式。
- 中文使用「不能」。

# 四、这12句话究竟能分析出什么？

把12句话放在一起，可以看到它们不是随意挑选的，而是一个精心设计的语法观察实验。

| 观察维度  | 对应句子  | 主要问题           |
| ----- | ----- | -------------- |
| 基本句型  | 1     | 主语、谓语、形容词如何组合？ |
| 所有关系  | 2     | 如何表达所属？        |
| 双宾语   | 3、4   | 谁给谁什么？         |
| 人称和格  | 4、5、6 | 我、他、她、它怎样变化？   |
| 动词变位  | 5、8   | 人称、数量是否影响动词？   |
| 疑问句   | 7     | 怎样提出问题？        |
| 名词复数  | 8     | 怎样表达一个和多个？     |
| 情态和义务 | 9     | 如何表达必须？        |
| 愿望    | 10    | 如何表达想做某事？      |
| 将来    | 11    | 如何表达未来？        |
| 否定和能力 | 12    | 如何表达不能？        |

另外，Ferriss 在书中还给出一个额外的第13句：

I have eaten the apple.

| 中文       | 英文                      | 日文             |
| -------- | ----------------------- | -------------- |
| 我已经吃了苹果。 | I have eaten the apple. | 私はそのりんごを食べました。 |

这句话可以观察英语现在完成时与其他语言过去时表达之间的差别。注意，日语「食べました」并不完全等同于英语现在完成时。

## 五、12金句法的评价和影响

### 1. 它的价值

我认为这个方法最有价值的不是12句话本身，而是它背后的三个学习思想。

第一：先看整体，再研究细节。

就像学习一套软件系统，先了解模块之间的关系，再深入每个类和方法。

第二：通过比较发现规律。

同样一句话，英语用词序和动词变化，日语用助词和动词活用，中文则更多依靠语序和虚词。

比较之后，语法不再是孤立的知识点。

第三：从简单句子中发现复杂系统。

12句话可以作为一张语言结构的缩略地图，帮助初学者快速建立认知框架。

### 2. 它的局限

不能把它理解为一种完整的语言学习方法。

| 局限      | 原因                 |
| ------- | ------------------ |
| 句子数量少   | 无法覆盖所有语法和词汇        |
| 过于依赖翻译  | 翻译正确不代表能自然表达       |
| 缺少语音    | 无法了解发音、语调和听力       |
| 缺少实际交流  | 不等于能够自由对话          |
| 语言之间差异大 | 相同句子在不同语言中可能需要不同表达 |

语言学者 Steve Kaufmann 在 LingQ 的文章中肯定了这种方法的启发价值，但也指出，12句不足以建立真正的语言熟练度，仍然需要大量听、读和实际使用。

- 想建立系统化语言学习计划的人。

# 六、如何用12金句法学习一门新语言？

这里我建议把它升级为一个实际可执行的方法：

12句 → 语法解构 → 句型扩展 → 听说读写 → 实际应用。

## 语言学习五个阶段

1. 第一阶段：建立12句基准

   找出12句在目标语言中的准确表达，最好由母语者校正。
2. 第二阶段：解构语法

   分析每个句子的词性、语序、动词变化、助词和时态。
3. 第三阶段：扩展句型

   每句话增加过去、现在、未来、肯定、否定、疑问等变化。
4. 第四阶段：听说读写

   听母语者朗读，跟读、默写、替换单词、独立造句。
5. 第五阶段：实际应用

   用这些句型进行真实对话、写作、阅读和工作交流。

## 1. 从一句话扩展出多个句子

例如第一句：

The apple is red.

不要只背这一句，而是进行替换练习：

| 类型 | 英文                     | 中文        |
| -- | ---------------------- | --------- |
| 肯定 | The apple is red.      | 苹果是红色的。   |
| 否定 | The apple isn't red.   | 苹果不是红色的。  |
| 疑问 | Is the apple red?      | 苹果是红色的吗？  |
| 复数 | The apples are red.    | 苹果是红色的。   |
| 过去 | The apple was red.     | 苹果当时是红色的。 |
| 将来 | The apple will be red. | 苹果将会变红。   |
| 比较 | This apple is redder.  | 这个苹果更红。   |

这样一句话就变成了一个句型家族。

## 2. 采用词语替换法

例如：

I give John the apple.

可以替换为：

- I give John the book.
- I give Mary the flower.
- I give him the key.
- I give her a gift.
- I gave him the book yesterday.

你会逐渐发现，掌握一个句型，就能表达许多不同的内容。

## 3. 利用间隔重复

推荐一个简单的复习周期：

| 时间   | 任务         |
| ---- | ---------- |
| 第1天  | 学习12句，理解结构 |
| 第2天  | 不看原文，尝试复述  |
| 第4天  | 替换单词，练习新句  |
| 第7天  | 听写和口头表达    |
| 第14天 | 用新语言讲一个小故事 |
| 第30天 | 实际对话和综合测试  |

工具可以使用：

- Anki：记忆卡片和间隔重复。
- 手机录音：比较自己的发音与母语者。
- ChatGPT：语法分析、句型扩展和情景对话。
- YouTube：寻找目标语言的真实语音材料。

## 八、从12句扩展到真正掌握一门语言

我还建议增加四个维度，使它不仅仅是语法分析工具。

语言能力的四个维度

听 Listening

听懂母语者的发音、语调和表达。

说 Speaking

不看原文，独立组织句子。

读 Reading

理解文章、语法和词汇。

写 Writing

自己写出完整、自然的表达。

### 九、我的建议：从12句发展为多语言对照学习体系

你已经在学习英语、日语、韩语、越南语等语言。可以把12句作为共同的基准，研究不同语言如何表达同一个意思。

例如：

- 英语：I give him the apple.
- 日语：私は彼にりんごをあげます。
- 韩语：나는 그에게 사과를 줍니다。
- 越南语：Tôi đưa quả táo cho anh ấy。

通过比较，可以发现：

- 英语主要依靠语序和介词。
- 日语主要依靠助词。
- 韩语也使用助词，并且动词通常放在句末。
- 越南语主要依靠语序和介词。

这比孤立地记忆四种语言的语法更容易形成整体认识。

最终，我建议把这个方法发展成一个自己的学习项目：

# 12 → 120 → 1200

- 12句：了解语言的基本结构。
- 120句：建立常见表达和句型体系。
- 1200句：通过真实语境积累词汇、表达和语言习惯。

12句负责打开大门，120句负责建立框架，1200句负责进入真实语言世界。

这也与我们前面讨论的复利思想相通：每掌握一个句型，就在已有知识上增加新的表达能力；不断扩展，最终形成自己的语言系统。

最重要的原则：不要只记住句子，要理解句子是怎样生成的，并且能够自己创造新的句子。
