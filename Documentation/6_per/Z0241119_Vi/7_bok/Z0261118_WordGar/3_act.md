# **一、「言葉」为什么由“言”和“叶”组成？**

新海诚的动画电影《言の葉の庭》（ことのはのにわ，通常译作《言叶之庭》），片名非常有诗意。

它不是简单地把“语言”和“树叶”拼在一起，而是使用了日语中一个古老而优美的表达：**言の葉（ことのは）**。

这里的“叶”，原本就有树叶的意思，但在这个词里，它还承载着一种古典文学中的意象：语言像树叶一样生长、繁茂，承载人的情感，也可能随风飘落。

先看三个相关词：

| 写法  | 读音             | 含义              |
| --- | -------------- | --------------- |
| 言   | こと（古典语中也有相关用法） | 言语、言辞           |
| 葉   | は              | 叶子              |
| 言の葉 | ことのは           | 言语、话语、诗文，带有文学色彩 |

现代日语中最常用的“语言、话语”是「言葉（ことば）」，而「言の葉」更偏向古典、诗意和文学表达。

## **1. 「言葉」的语源与语义**

「言葉」读作：

- 假名：ことば
- 罗马音：kotoba
- 中文：语言、话语、词语、言辞
- 英语：word / words / language

它的历史需要分开看。

古日语中存在「こと」这个词，既可以指言语、言辞，也可以指事情、事实。后来「ことば」逐渐成为表示言语、词句的常用词。

至于「ば」的来源，常见解释与「端（は）」有关，也有其他语源解释。不能把它简单理解成现代汉语的“叶子”直接变成了「ば」。

那么，为什么又有「言の葉」？

日本古典文学中，「言の葉」是一种富有诗意的表达。它将言语比作叶子，使抽象的语言获得了植物般的生命感。

因此，两种表达的侧重点不同：

- **言葉**：日常交流中的语言、词语。
- **言の葉**：有文学感的言辞、情感的表达、诗歌与话语。

值得注意的是，现代汉字「言葉」中的「葉」虽然写作“叶”，但不能因此认定这个词最初就是“语言＋树叶”的简单组合。它的词源解释仍有争议。

## **二、「言の葉」为什么写成“叶”？——日本古典文学中的植物意象**

这部分是理解电影标题的关键。

### **1. 「言の葉」在古典文学中确实存在**

《竹取物语》（约9世纪末至10世纪初）中已经出现「ことのは」：

> まことかと聞きて見つれば\
> ことのはを飾れる玉の枝にぞありける

这里的「ことのは」指言辞、话语。

《古今和歌集》（905—914年编纂）的假名序中，又有一句非常重要的话：

> やまとうたは、人の心をたねとして、よろづのことの葉とぞなれりける。

中文可以理解为：

> 日本和歌以人的心为种子，最终生长为万千言语之叶。

这句话把诗歌的产生描写成植物生长的过程：

# **心（こころ）**

种子：人的情感、思念、体验

# **言葉（ことば）**

生长：内心变成可以表达的话语

# **言の葉（ことのは）**

枝叶：诗歌、言辞、情感的表达

这并不是说所有日本人都认为语言真的像树叶一样，而是古典和歌借助植物意象，将人的心与诗歌联系起来。

《古今和歌集》的这句话，也可以说是理解《言叶之庭》标题的一个重要文化背景。

### **2. 「言葉」和「言の葉」有什么差别？**

还有一个很值得注意的细节。

《日本国語大辞典》所收录的资料显示：

- 「言葉」在《万叶集》中已有早期用例。
- 「言の葉」在《竹取物语》中有明确用例。
- 「言の葉」在和歌中还可以与真正的树叶形成双关，表示爱情话语、人们的传闻等。

例如小野小町的和歌：

> 今はとて\
> わが身時雨に\
> ふりぬれば\
> 事のはさへに\
> うつろひにけり

大意是：

> 如今，我的身影已如秋雨中的落叶般衰老，连那些曾经的言语，也已经改变了颜色。

这里的「事のは」与「木の葉」形成双关，表达情感的变迁。

所以，日语里的「言の葉」不只是一个古雅的“语言”同义词。它还可以让人联想到：

- 一句话像一片叶子，承载着一个人的心意；
- 话语会生长，也会凋零；
- 爱情可以通过言语表达，也可以因为言语改变而消逝；
- 有些情感，即使没有说出口，也仍然存在。

这正是新海诚选择「言の葉」而不是普通的「言葉」所能产生的文学效果。

### **故事梗概**

故事发生在现代东京。

15岁的高中生秋月孝雄，梦想成为制鞋师傅。由于对学校生活缺乏兴趣，他常常在下雨的早晨逃课，到公园的日本庭园里画鞋的设计图。

在那里，他遇见了一位神秘的成年女性——雪野百香里。

雪野独自坐在庭园里喝啤酒，似乎正在逃避自己的工作与生活。

两个人没有约定，却逐渐形成了一种默契：

**只要下雨，就可能在庭园里再次相遇。**

他们谈论生活、梦想和烦恼。孝雄想为雪野制作一双鞋，让她重新获得行走的勇气。

但两个人之间存在年龄、身份、社会关系和人生阶段的巨大差异。

雨季即将结束，他们之间的关系也不得不面对现实。

制作公司对故事的概括是：这不是一个已经抵达爱情的故事，而是一个关于孤独、思念，以及在爱到来之前，人如何寻找彼此的故事。

电影中，雪野向孝雄留下了一首《万叶集》的和歌：

> 鳴る神の\
> 少し響みて\
> さし曇り\
> 雨も降らぬか\
> 君を留めむ

作者为柿本人麻吕。

大意是：

> 雷神啊，请稍稍响起，让天空阴沉下来，最好能下一场雨，这样我就能把你留在身边。

这首诗很重要。

它不是单纯写雨，而是写一个人希望借助天气，留住即将离开的人。

雨在这里成了情感的媒介：

- 下雨，便有理由相见；
- 雨停，便可能分别；
- 希望雨一直下，其实是希望对方不要离开。

电影的整个情感结构，几乎都可以从这首和歌中找到线索。

## **六、电影中最值得分析的五个象征**

### **1. 庭院：一个暂时脱离社会规则的空间**

[Kotonoha no Niwa, de Makoto Shinkai, en castellano](https://images.openai.com/static-rsc-4/261iqTESoYTgDypRzgdOMafYBEvF-32whOkDtRN1KqpmM25lr16qPUXhnEqMi7L_2BoFF49zx171zpx81UNGYreuNJdQsGU738klfX3K_XNpwdQ-MA1vmGzZ82wXdA4ovmCunEjz1R0IZaklWEVgwjRuqZDcpeNmTI9PbEZ61wA?purpose=inline)

[hobbyconsolas.com](https://www.hobbyconsolas.com/noticias/kotonoha-no-niwa-makoto-shinkai-castellano-64805?utm_source=chatgpt.com)

学校、家庭、职场都代表现实社会中的身份。

孝雄在学校里是学生，雪野在社会中是教师。

但在庭园里，他们暂时不用扮演这些角色。

他们可以只是两个有烦恼、有梦想、需要被理解的人。

所以庭园不是单纯的背景，而是两个人暂时获得心理安全感的空间。

### **2. 雨：人与人相遇的理由**

雨既是阻隔，也是连接。

它让人不能正常出行，却让两个人有机会相见。

更深一层，雨也象征两个人暂时没有办法控制的人生处境。

他们不能决定所有事情，却可以在某个下雨的早晨，决定是否来到庭园。

### **3. 鞋：重新获得行走的能力**

[新海誠監督 初のオンラインサイン会が開催【アニメイト通販限定】 | アニメイトタイムズ](https://images.openai.com/static-rsc-4/cjyUOVdqla4kGsgDz5WhIxNonAf5-EjYG2JTBOiqPh1UKlVntiojKNJrHC_4kqItNwASC_opStBrJFRIlWpDuTq2we6sRQSUpGXJJpve7_MIxDqk9n8X83_tqEt_IyOt7p2VNfI7YJr8bHRP9zxtayABY_ybzX_jOb4Zf_qfWFo?purpose=inline)

[animatetimes.com](https://www.animatetimes.com/news/img.php?id=1623228587\&n=9\&p=1\&utm_source=chatgpt.com)

孝雄的梦想是成为制鞋师傅。

他希望制作一双鞋，让雪野重新走起来。

这其实也是一种心理上的愿望：

- 雪野失去了生活的方向；
- 孝雄希望自己能够帮助她；
- 他把无法直接表达的情感，转化为制作一双鞋的行动。

鞋在这里不只是商品，而是行动能力、独立生活和重新出发的象征。

不过，电影也留下了一个重要问题：一个人可以帮助另一个人，但不能完全替另一个人走完人生。

### **4. 和歌：古代语言与现代情感的连接**

《万叶集》的和歌，跨越一千多年，进入两个现代东京人的生活。

这意味着人的情感虽然受到时代、社会和文化影响，但孤独、思念、希望留住一个人的心情，并没有根本改变。

这也使电影标题「言の葉」有了更深的含义：

**语言不仅记录情感，也让不同时代的人能够彼此理解。**

### **5. 沉默：有些情感不是语言能够直接表达的**

电影中两个人有不少对话，但真正重要的情感，常常通过眼神、动作、距离、天气和环境表达。

这与新海诚的动画风格有关。

他很重视背景、声音、光线、色彩和人物细微的表情，让观众不仅听到人物说什么，还能感受到他们没有说出来的东西。

### **3. 文化影响**

它的影响可以从几个方面观察：

- **日本古典文学重新进入现代动画**：让《万叶集》和古典和歌被更多年轻观众接触。
- **城市空间成为动画叙事的一部分**：新宿御苑等真实地点成为影迷旅行与实地探访的对象。
- **动画短片的电影表达**：证明不一定需要两小时的长篇叙事，也可以通过较短篇幅表达完整而复杂的情绪。
- **新海诚个人风格的延续**：雨、光、距离、季节、音乐和未完成的情感，成为他作品中反复出现的元素。

日本文化厅媒体艺术祭将其列为第17届动画部门审查委员推荐作品。这个认可可以证明其获得了专业评审的关注，但不等于所有评论家或观众都对其评价一致。

## **八、回到电影标题：为什么叫《言の葉の庭》？**

我认为这个标题至少有四层含义。

| 层次 | 含义                 |
| -- | ------------------ |
| 字面 | 话语之庭、言语的庭园         |
| 文学 | 人心如种子，语言如枝叶        |
| 故事 | 两个孤独的人在庭园中通过言语建立联系 |
| 哲学 | 人的内心需要表达，也需要被理解    |

这里还有一个值得玩味的地方：

庭园里的植物不需要说话，却能够通过颜色、形态、季节和生长表达生命。

而人类能够说话，却经常无法准确表达自己的心。

电影中的两个人就是如此：

他们在雨中相遇，开始说话；但他们真正想表达的情感，并不是每次都能通过语言完整传达。

因此，标题中的「言の葉」也可以理解成一种诗意的矛盾：

**人有语言，却未必能够说出自己的心；人没有说出口的情感，却仍然可以像叶子一样，在两个人之间生长。**

## **九、日语和英语学习：从这部电影记住几个词**

| 日语   | 读音      | 英语                       | 中文        |
| ---- | ------- | ------------------------ | --------- |
| 言葉   | ことば     | words / language         | 语言、话语     |
| 言の葉  | ことのは    | poetic words             | 诗意的言辞     |
| 庭    | にわ      | garden                   | 庭园        |
| 孤独   | こどく     | loneliness               | 孤独        |
| 孤悲   | こい      | longing / yearning       | 思慕、孤独的恋情  |
| 雨宿り  | あまやどり   | taking shelter from rain | 避雨        |
| 梅雨   | つゆ      | rainy season             | 梅雨季       |
| 和歌   | わか      | waka poetry              | 日本古典和歌    |
| 靴職人  | くつしょくにん | shoemaker                | 鞋匠        |
| 歩き出す | あるきだす   | start walking            | 迈出脚步、重新出发 |

特别记住：

- 孤独（こどく）：loneliness，孤独的状态。
- 孤悲（こい）：电影宣传语中用来表现古典式的恋慕与思念。
- 恋（こい）：爱情、恋慕。

电影宣传语：

> 「愛」よりも昔、「孤悲」のものがたり。

直译：

> 这是一个比“爱”更早、名为“孤悲”的故事。

这句话不是说古代日本没有爱情，而是借用「孤悲」这一古典式的文字意象，强调人在真正建立爱情和关系之前，那种孤独地思念另一个人的状态。

**最后，我想把这部电影与《言葉》本身联系起来：**

《古今和歌集》说，和歌以人的心为种子，生长为万千言语之叶。

《言叶之庭》则仿佛把这个过程拍成了一部电影：人的孤独是种子，雨天是土壤，庭园是生长的空间，而两个人之间那些没有说完的话，就是慢慢长出来的叶子。

如果想进一步体会它的文学底蕴，可以把电影中的《万叶集》原诗、《古今和歌集》假名序和秦基博演唱的《Rain》放在一起欣赏。
